MONOLITH BUILDERS & MATERIALS - demo website
============================================
Open index.html in a browser. No server or build step needed.

Files (all in one flat folder)
  *.jpg          11 generated architectural images (hero, residential, commercial, ...)
  hero-bg*.mp4/webm, hero-poster.jpg  looping hero background video and poster

Quick edits (top of script.js, CONFIG block)
  WHATSAPP_NUMBER  digits only with country code, e.g. 2348012345678
  TELEPHONE, EMAIL, SERVICE_AREAS
  IMAGES           swap any file name or URL for a real photograph
  VIDEO            set to '' to use the CSS-only animated background instead

Notes
  - Images and video are generated illustrations, not photographs.
  - Fonts load from Google Fonts and fall back to system fonts offline.
  - Products, projects and areas are labelled demo content.
